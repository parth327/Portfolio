About

The short version — where I've worked, and what I do, day to day.

I'm a software developer based in Ahmedabad, India, five years into a career spent almost entirely on operational software — the kind that rarely gets a design award, but has to work correctly every single day because a shift supervisor or a sales team is depending on it right now.

I started at Radixweb learning the .NET fundamentals, spent two years at Inflibnet Centre building sales and support tooling for a nationwide library platform, and I'm now a Senior Software Developer at Chattary Ajwan Infotech, building contractor-allocation systems for a thermal power station.

More recently, Claude and Claude Code have become part of how I actually build — not a novelty, a real shift in how fast I can take a system from spec to shipped, without loosening my own standards for what ships.

I studied Computer Science at GEC Modasa (GTU), and I still think the details — whether something looks right, not just runs right — are worth the extra pass.

AI-augmented workflow

Claude Code is where most of my build time goes now — not for one-off snippets, but for taking a spec to a running, tested web application in a single sitting, without giving up the accuracy of a hand-written system.

01 · SPEC

Turn a spec into structure

Feed Claude Code the requirements and it scaffolds routes, models, migrations, and auth together — not stitched from separate generations.

02 · BUILD

Full app, one sitting

Front end, back end, and database wired to each other the same day — a working system, not a folder of disconnected files.

03 · VERIFY

Reviewed, not blind

Every generated piece gets read, run, and corrected before it ships — Claude drafts the system, I own what ships.

04 · SHIP

Tested, committed, shipped

Every build ends with a passing test run and a clean, reviewed git history — not a pile of uncommitted changes handed off as "done."

Frequently asked

The questions that usually come up before we start.

Are you open to full-time roles, or freelance work?

Primarily full-time roles — that's what I'm actively looking for right now. I'll also consider a scoped freelance project if it's a strong fit, but a full-time seat is the priority.

Do you work with existing codebases, or only new builds?

Mostly existing systems, honestly — maintaining and extending software I didn't originally write is most of my day-to-day at Inflibnet and now at Chattary Ajwan. New builds are the exception, not the rule.

What industries have you worked in?

Power infrastructure (contractor and workforce allocation), academia (a nationwide library platform), and event management — mostly systems that run quietly in the background of much bigger operations.

Is Claude Code writing code without review?

No. Claude Code speeds up the build, but everything gets read, run, and corrected by me before it ships. I'm still the one who understands the system end to end — and I'm the one accountable if something breaks.

Where are you based, and can you work with remote teams?

Ahmedabad, India (IST) — I work async with remote and international teams regularly; time zones haven't been a blocker yet.
