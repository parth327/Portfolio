About

The short version — where I've worked, and what I actually do day to day.

I'm a software developer based in Ahmedabad, India — five years into building the kind of software that businesses actually run on: allocation systems, sales tooling, reporting. The operational software that rarely gets a design award but has to work correctly every single day.

I started at Radixweb learning the .NET fundamentals, spent two years at Inflibnet Centre building sales and support tooling for a nationwide library platform, and I'm now a Senior Software Developer at Chattary Ajwan Infotech, building contractor-allocation systems for a thermal power station.

More recently, Claude and Claude Code have become part of how I actually build — not a novelty, a real shift in how fast I can take a system from spec to shipped, without loosening my own standards for what ships.

I studied Computer Science at GEC Modasa (GTU), and I still think the details — whether something looks right, not just runs right — are worth the extra pass.

AI-augmented workflow

Claude Code is where most of my build time goes now — not for one-off snippets, but for taking a spec to a running, tested web application in a single sitting, without giving up the accuracy of a hand-written system.

01 · SPEC

Turn a spec into structure

Feed Claude Code the requirements and it scaffolds routes, models, migrations, and auth together — not stitched from separate generations.

02 · BUILD

Full app, one sitting

Front end, back end, and database wired to each other the same day — a working system, not a folder of disconnected files.

03 · VERIFY

Reviewed, not blind

Every generated piece gets read, run, and corrected before it ships — Claude drafts the system, I'm still the one who signs off on it.

Frequently asked

Are you open to full-time roles, or freelance work?

Both. I'm currently open to opportunities — happy to talk through whether a full-time role or a scoped freelance project makes more sense for what you're building.

What industries have you worked in?

Ahmedabad, India (IST). Comfortable working async with remote and international teams.
